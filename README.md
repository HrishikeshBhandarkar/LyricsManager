## 🚧 Project Status
> **Note:** This project is currently under active development. Current features focus on API integration, XML/TTML parsing, and ELRC conversion testing.

## ✨ Features
* 🖥️ **Terminal-Native:** Clean, lightweight command-line workflow with zero heavy GUI overhead.
* 🎵 **Metadata Extraction:** Reads local `.mp3` and `.flac` tags automatically.
* ⏱️ **TTML to ELRC Converter:** Converts Apple Music word-level XML timestamps (`.ttml`) into Enhanced LRC format (`.elrc`).
* 🔌 **Modular API Support:** Connects directly to LRCLIB and BiniLyrics endpoints.
