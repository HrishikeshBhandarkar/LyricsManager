In plain terms: Whisper is brilliant at hearing the words — but its timestamps are only segment-accurate (per ~5–30 s chunk). That is useless for karaoke-style lyrics. WhisperX fixes the time part: it takes the words Whisper already heard and runs a second, lightweight neural net (Wav2Vec2 phoneme alignment) that walks through the audio phoneme-by-phoneme and stamps every single word to the exact millisecond it was sung.

Whisper alone

  • Timestamps at segment level — 5 to 30 second chunks
  • Good for subtitles, transcripts, meeting notes
  • No word-level timing; cannot drive sing-along UIs
  • Timestamps can drift mid-song

WhisperX (this project)

  • Forced alignment → per-word start & end times
  • Phoneme-level precision, typically ± tens of ms
  • Directly powers word-by-word lyric players
  • Output survives as .elrc you already support

formatters.pypython
def ms_to_lrc_time(seconds: float) -> str:
    minutes = int(seconds // 60)
    secs = seconds % 60
    return f"{minutes:02d}:{secs:05.2f}"

def format_elrc(words: list[dict]) -> str:
    lines, current_line, line_start = [], [], None

    for i, w in enumerate(words):
        if not current_line:
            line_start = w["start"]
        current_line.append((w["start"], w["word"]))

        # Break on long pauses (tune threshold)
        next_w = words[i + 1] if w != words[-1] else None
        if next_w and (next_w["start"] - w["end"]) > 2.0:
            lines.append((line_start, current_line))
            current_line, line_start = [], None

    if current_line:
        lines.append((line_start, current_line))

    return "\n".join(
        f"[{ms_to_lrc_time(ls)}]"
        + " ".join(f"<{ms_to_lrc_time(t)}>{w}" for t, w in wl)
        for ls, wl in lines
    )

Handy Code Snippets

Patterns you will need along the way — copy and adapt. WhisperX expects a 16 kHz mono numpy array.

audio.py — load 16kpython
import torchaudio

def load_audio_16k(path: str | Path) -> tuple:
    waveform, sr = torchaudio.load(path)
    if waveform.shape[0] > 1:
        waveform = torch.mean(waveform, dim=0, keepdim=True)
    if sr != 16000:
        resampler = torchaudio.transforms.Resample(sr, 16000)
        waveform = resampler(waveform)
    return waveform.squeeze().numpy(), 16000
audio.py — instrumental checkpython
def has_vocals(segments: list[dict], min_words: int = 5) -> bool:
    words = [w for seg in segments for w in seg.get("words", [])]
    return len(words) >= min_words
io.py — save sidecarpython
def save_sidecar(audio_path: str | Path, elrc_text: str) -> Path:
    audio_path = Path(audio_path)
    elrc_path = audio_path.with_suffix(audio_path.suffix + ".elrc")
    elrc_path.write_text(elrc_text, encoding="utf-8")
    return elrc_path
08Guidelines

Do's & Don'ts

Operational rules distilled from real WhisperX usage — read once, honor every build.

⟶ Approved Operations
DoWhy
✓ Cache transcriptionsModels are slow; audio files don't change
✓ Allow model size choice (tiny → large-v2)Balance accuracy vs. speed
✓ Use language hint from metadataFaster + more accurate transcription
✓ Batch process multiple songsReuse loaded model in memory
✓ Validate with is_truly_enhanced()Avoid fake/empty ELRC files
✓ Align on downmixed mono 16 kHzWhisperX expects this format
✓ Provide CPU fallbackNot everyone has a GPU
⟶ Restricted Operations
Don'tWhy
✕ Run WhisperX on every launchHeavy process; make it opt-in
✕ Trust word timestamps blindlyAlignment drifts, especially with music
✕ Process >10 min files in one goMemory spikes; chunk instead
✕ Ignore faster-whisper dependencyWhisperX wraps it; install explicitly
✕ Hardcode model pathsUse whisperx.load_model() defaults
✕ Forget to free GPU memorytorch.cuda.empty_cache() after batch
✕ Skip validationEmpty/misaligned lyrics are worse than none
